# Phase 0 — Foundation

Status: **Complete**

Phase 0 establishes the technical baseline for Kognia before product modules are developed.

## Delivered

- Monorepo structure
- `main`, `dev`, and `feature/*` branch flow
- .NET 10 backend solution
- Clean Architecture projects
- EF Core + SQL Server persistence baseline
- `KogniaDbContext`
- Application and Infrastructure DI modules
- `/health` endpoint
- React 19 + TypeScript + Vite frontend
- React Router application shell
- TanStack Query provider
- ESLint configuration
- Docker Compose SQL Server environment
- Backend architecture smoke test
- GitHub Actions CI
- Architecture documentation
- Product roadmap

## Exit criteria

Phase 0 is considered complete because the repository now has a buildable architecture baseline, persistence wiring, frontend application shell, automated validation pipeline, and documented development workflow.

The next implementation milestone is **Phase 1 — Identity**.
