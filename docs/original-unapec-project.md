# Original UNAPEC Project

Kognia originated from an academic final project developed at **Universidad APEC (UNAPEC)** for the course **Gestión de Sitios Web (ISO-700)** during the **May–August 2024** academic period.

## Original Concept

The academic project proposed an e-learning platform based on a subscription model, giving users access to a library of digital courses and learning content. The original concept included user registration and login, course discovery, enrollment, content consumption, progress tracking, usability and accessibility considerations, and a subscription-based business model.

The original academic work also explored market positioning, objectives and KPIs, SWOT and PESTEL analyses, Scrum as the development methodology, user flows, wireframing, accessibility, monetization, and return-on-investment projections.

## 2026 Reconstruction

In 2026, the original concept was recovered and rebuilt from the ground up under the name **Kognia** as a production-oriented SaaS learning platform.

The reconstruction preserves the core academic idea while expanding it into a modern software product with a real technical architecture, including:

- .NET 10 / ASP.NET Core Web API
- Clean Architecture
- Entity Framework Core
- SQL Server
- React 19
- TypeScript
- Vite
- React Router
- TanStack Query
- Docker Compose
- GitHub Actions
- Automated tests

Kognia's modern roadmap expands the original concept toward learning paths, assessments, certifications, subscriptions, learner analytics, instructor tooling, administration, and commercial hardening.
